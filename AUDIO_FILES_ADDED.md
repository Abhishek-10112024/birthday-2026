## 🐛 Troubleshooting

### Music doesn't play
1. Check browser console for errors
2. Make sure you clicked a button (autoplay requires interaction)
3. Check if mute button is enabled
4. Try hard refresh (Cmd+Shift+R)

### Sound effects don't play or are too quiet
- Check if audio is muted
- Sound effects play at 40% volume
- Adjust volume in `audio.service.ts` if needed

### Music is too loud
- Edit `src/app/services/audio.service.ts`
- Change `volume = signal<number>(0.3)` to a lower value (e.g., 0.2)
