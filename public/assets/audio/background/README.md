# Background Music

Place your ambient background music file here.

## Required File
- **ambient-space.mp3** - Main background music for the landing page

## Specifications
- **Format**: MP3 (best browser compatibility)
- **Duration**: 2-5 minutes (will loop automatically)
- **File Size**: < 2MB recommended
- **Bitrate**: 128kbps
- **Style**: Ambient, ethereal, calm, space-themed
- **Volume**: Mixed at -20dB (quiet, non-intrusive)
