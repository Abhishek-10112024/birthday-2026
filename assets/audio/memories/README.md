# Memory Audio Files

Place memory-specific audio files here (optional feature for future).

## File Naming
- **memory-1-audio.mp3** - Audio for first memory
- **memory-2-audio.mp3** - Audio for second memory
- etc.

## Specifications
- **Format**: MP3
- **Duration**: 30 seconds - 2 minutes
- **File Size**: < 1MB per file
- **Bitrate**: 128kbps
- **Type**: Voice memos, music clips, ambient sounds

## Use Cases
- Voice recordings of the memory
- Song that was playing during the memory
- Ambient sounds from the location
- Personal messages

## Future Feature
This is a placeholder for future implementation where each memory can have its own audio clip that plays in the memory dialog.
